DynamicRawStringFactory

interface DynamicRawStringFactory : RawStringFactory

A raw string factory allows you to abstract the generation of raw string for GenericGdObjects. Internally, the default implementation uses reflection to look for PropertyDefinitions and create the raw string from there.

A dynamic raw string factory however allows the user to add any properties dependant of the factory's linked object at runtime.
